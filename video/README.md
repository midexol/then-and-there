# Then & There: demo video

Two renders come out of this folder (see `out/` after rendering):

- `then-and-there-demo.mp4`: energetic voiceover (Microsoft neural voice "Aria", +12% rate) over the soundtrack.
- `then-and-there-demo-novoice.mp4`: the same picture and soundtrack, no voice, so you can record your own over it.

Total length about 70 seconds, 1920x1080, 30 fps. The pictures are real screenshots of the live app at phone size. The build scene is a real build, sped up. Nothing in the video is mocked up.

## Rebuild it

```bash
cd video
npm install
python scripts/make-voice.py      # voiceover (needs internet; edit script.json to change words or voice)
python scripts/make-music.py      # soundtrack, synthesized here, nothing to license
node scripts/make-timeline.mjs    # scene timings from the real audio lengths
npm run studio                    # preview
npm run render                    # with voiceover
npm run render:novoice            # without
```

The screenshots in `public/shots` come from `scripts/capture.mjs` (Playwright, against the live app). Audio and screenshots are not committed; the scripts regenerate them.

## Notes on the voice and music

- The voice comes from Microsoft's online text-to-speech through the `edge-tts` package. Only the script text above is sent.
- The music is generated by `scripts/make-music.py`: a pad, a plucked arpeggio, bass and a light beat in C - G - Am - F at 104 BPM. It is original, so there is nothing to credit.
- The video makes no health or memory claims, in line with the app's own copy.
